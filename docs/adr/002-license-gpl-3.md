# ADR-002 — License: GPL-3

**Status:** accepted, r1
godip is GPL-3 and its map assets ship with it. The whole project is
therefore GPL-3. This is a consequence of ADR-001, not an independent choice.
If a permissive license is later required, both ADR-001 and ADR-003 must be
reopened together.
